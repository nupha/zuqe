# GC field audit exemptions — one `Type.field — reason` entry per line.
# Blank lines and `#` comments are skipped.
#
# Single source of truth for the audit: read by `tests/gc_audit.rs` (via
# `zuqe::gc_audit_test!`) and `zuqe-gc-audit`. Do not keep exemptions elsewhere.
# Each entry is a reviewed claim (treat like code): this `Type.field` needs no
# write barrier of its own. A stale entry (field gone/renamed/wrapped, or
# naturally passes) fails the audit.
#
# Legitimate categories (the field still gets audited; exemption is per-field):
# 1. root containers — a minor GC force-descends them, so a barrier is pointless;
# 2. construction-only — the value is stored only while the instance is young
#    (no late write after promotion), so no old→young edge is created;
# 3. structural non-goals (not a target for WriteBarrier guard wrapping; handle
#    by other structure + a reviewed exemption):
#    - raw-pointer mirror (e.g. `*mut/*const` to a buffer): not a GC-traced
#      edge; buffer/slots are traced elsewhere (e.g. stack roots).
#    - `Cell` slot with a single setter that stores and binds: guard slots are
#      deliberately not `Copy`; interior mutation must go through that one path.
#    - untraced weak target (`GcWeak` / weak edge): never a strong edge to bind.
#    - composite shape: keep GC fields private and route every post-construction
#      write through setters that bind (no guard-slot wrapping of the shape).
